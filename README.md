# Nutrition Education Management System (NEMS)

**Course:** CSE326 (GC) | **Faculty IDs:** 43, 46, 60

A single-page web app for managing nutrition education programs: content, sessions, participants, resources, quizzes, attendance, feedback and a live progress dashboard. Data is saved in the browser with localStorage.

**Live site:** https://vegolamsathwikgoud-debug.github.io/nems/

## Modules

1. Content Library: search, filter, add, delete
2. Session Scheduling: title, educator, date, time, capacity, status
3. Participant Registration: session mapping, capacity and duplicate checks
4. Resources: worksheets, posters, templates, learning materials
5. Quizzes / Check-ins: 5-question quiz with attempt history
6. Attendance: present/absent tracking
7. Feedback: ratings, comments, average
8. Progress Summary: live dashboard
9. Admin Controls: roles and demo data reset

## Run locally

Open `index.html` in any browser. No build step is needed.

## Tech

HTML, JavaScript, Tailwind CSS (CDN), Lucide icons.
